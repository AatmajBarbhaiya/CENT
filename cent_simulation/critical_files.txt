cent_simulation/aim_sim.py - PIM abstraction and AiM op emission (trace-only wrappers: WR_GB, WR_BIAS, MAC_ABK, RD_MAC, EWMUL, COPY_BKGB, COPY_GBBK, AF, RD_AF, SYNC, EOC). Implements timing accounting and helpers for trace generation.

cent_simulation/TransformerBlock.py - Core mapping of Transformer GEMV/GEMM to PIM ops; memory mapping, store/load multi-channel helpers, and Vector_Matrix_Mul_*_only_trace implementations that emit AiM sequences.

cent_simulation/Llama.py - LLaMA-specific TransformerBlock subclass with `self_attention_aim`, `FFN_aim`, and `trace_only` flows that call TransformerBlock PIM-only wrappers to produce the AiM trace.

cent_simulation/GPT.py - GPT mapper and trace-only flows (parallel to Llama) for generating AiM traces for GPT-style layers.

cent_simulation/function_sim.py - Driver harness: constructs the dummy model, runs `memory_mapping()` and `trace_only()` modes, and writes the AiM trace file. Use this as the entry point for trace generation.

cent_simulation/utils.py - CLI argument parsing and helpers (rotary embedding, RMSNorm, constants). Controls many CLI flags used to produce the sample trace.

cent_simulation/run_single_trace.sh - Convenience wrapper to reproduce the single-token LLaMA trace used during analysis.

cent_simulation/sample_aim.trace - Raw single-token AiM trace (generated by the harness).

cent_simulation/sample_aim.annotated.trace - Annotated version of the AiM trace (each AiM line is followed by emitter wrapper and likely caller information).

cent_simulation/README.md - High-level README produced during analysis: call graph, mermaid diagram text, and usage notes for generating traces.

cent_simulation/diagram.png - Rendered diagram (mermaid → PNG) mapping modules and dataflows.

aim_simulator/CMakeLists.txt - Build configuration for the cycle-accurate AiM simulator.

aim_simulator/build/ramulator2 (or `libramulator.so`) - Compiled simulator artifacts (binary/library) that consume AiM traces for cycle-accurate simulation (found under `build/`).

aim_simulator/src/ - Simulator C++ sources (trace parser, timing engine, DRAM models). Responsible for parsing AiM trace format and simulating cycles.

aim_simulator/README.md - Build/run instructions for the simulator; points at the C++ sources and built binaries.

Notes:
- The most important Python files for generating op-level traces are `aim_sim.py`, `TransformerBlock.py`, `Llama.py`, `GPT.py`, and `function_sim.py`.
- The simulator side (C++) is in `aim_simulator/` — use `CMakeLists.txt` and the `build/` outputs to run the generated trace with the cycle-accurate engine.
